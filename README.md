🌐 IP Calculator (IPv6) — быстрый расчёт IPv6-подсетей

> «IPv6 — это бесконечность, но мы знаем каждый бит»

**IP Calculator (IPv6)** — это набор консольных утилит для расчёта параметров IPv6-подсетей.  
Программа принимает на вход IPv6-адрес и префикс (например, `2001:db8::/32`) и выводит информацию о сети: сетевой адрес, маску, диапазон хостов, количество адресов, а также может разбивать на подсети.

## 🚀 Особенности
- 📋 Поддержка полного и сокращённого формата IPv6.
- 🔢 Расчёт сетевого адреса, маски подсети, wildcard.
- 📊 Вывод диапазона доступных хостов (первый и последний адрес).
- 📈 Подсчёт количества адресов в подсети.
- 🎨 Цветной вывод в терминале.
- 📤 Экспорт результатов в JSON и CSV.
- 🧠 Поддержка произвольной длины префикса (0-128).
- 🔄 Разбиение сети на подсети заданного размера (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python ip_calculator.py 2001:db8::/32` |
| Go         | стандартная библиотека               | `go run ip_calculator.go 2001:db8::/32`|
| JavaScript | Node.js, `fs` (встроенный)           | `node ip_calculator.js 2001:db8::/32`  |
| Java       | стандартная библиотека               | `javac ip_calculator.java && java ip_calculator 2001:db8::/32` |
| C#         | .NET (или mono)                      | `dotnet run 2001:db8::/32`             |
| Rust       | `std::net`, `serde`, `serde_json`    | `cargo run -- 2001:db8::/32`           |
| Ruby       | `ipaddr` (встроенный)                | `ruby ip_calculator.rb 2001:db8::/32`  |
| PHP        | стандартная библиотека               | `php ip_calculator.php 2001:db8::/32`  |
